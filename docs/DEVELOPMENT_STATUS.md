# SoloMine development status

Status: pre-alpha. No mining implementation or developer-fee payout code has been released or tested.

Planned: self-hosted Bitcoin solo mining based on CKPool, with a clearly disclosed 2% developer fee on successfully mined block rewards. All consensus-critical coinbase construction must be tested before mainnet use.

Upstream CKPool: https://github.com/ckolivas/ckpool

Do not use this repository for production mining yet.
